تعلم HTML من الصفر: بناء أول صفحة ويب خطوة بخطوة

كل موقع يبدأ بمحتوى منظّم. في هذا الدليل ستتعلم كيف تكتب بنية صفحة HTML، وتضيف العناوين والروابط والصور والقوائم والنماذج، ثم تستخدم العناصر الدلالية لبناء صفحة واضحة وسهلة الوصول.

إذا فتحت صفحة ويب، فالعناوين والفقرات والصور والروابط التي تراها لها بنية يقرأها المتصفح. لغة HTML هي اللغة القياسية لوصف هذه البنية. لا تحتاج إلى خبرة برمجية سابقة لتبدأ؛ يكفي محرر نصوص ومتصفح، ثم تتعلم بإضافة عنصر وتجربة النتيجة.

ما HTML؟

HTML اختصار لـ HyperText Markup Language، أي لغة ترميز النص التشعبي. هي ليست لغة برمجة بالمعنى المعتاد؛ بل تستخدم عناصر وعلامات لوصف أجزاء المحتوى. تتعاون مع CSS لتنسيق الصفحة ومع JavaScript لإضافة السلوك والتفاعل.

غالبًا يتكون العنصر من وسم بداية ومحتوى ووسم نهاية. مثلًا، <p> يحدد فقرة و</p> ينهيها. توجد عناصر فارغة لا تحتاج إلى وسم إغلاق منفصل، مثل <img>.

ابدأ بهيكل صفحة HTML

أنشئ ملفًا باسم index.html واكتب الهيكل الأساسي. يخبر <!doctype html> المتصفح باستخدام HTML الحديثة، ويحتوي <head> على معلومات الصفحة، بينما يحتوي <body> على المحتوى الظاهر.

تحدد الخاصية lang لغة المحتوى، وتضبط dir اتجاه الكتابة. وتساعد قيمة viewport صفحات الهاتف على استخدام عرض الشاشة الصحيح.

العناوين والفقرات والنصوص

استخدم العناوين من <h1> إلى <h6> بحسب ترتيب المحتوى، لا لمجرد تكبير الخط. غالبًا يكون للصفحة عنوان رئيسي واحد، تتبعه عناوين فرعية مرتبة. أما الفقرة فتكتب داخل <p>.

للتأكيد الدلالي استخدم <strong> للأهمية و<em> للتشديد، بدل اختيار عنصر اعتمادًا على شكله المرئي فقط.

الروابط والصور

ينشئ عنصر <a> رابطًا، وتحدد الخاصية href وجهته. أضف نصًا مفهومًا للرابط ليعرف الزائر أين سيذهب. وتعرض <img> صورة؛ أما النص البديل alt فيصف معناها عند تعذر تحميلها أو عند استخدام قارئ شاشة.

لا تكتب وصفًا عامًا مثل «صورة» في alt؛ صف ما يحتاج القارئ إلى معرفته. وإذا كانت الصورة زخرفية بحتة ولا تضيف معنى، يمكن ترك الوصف فارغًا: alt="".

القوائم والجداول

استخدم <ul> لقائمة غير مرتبة، و<ol> لخطوات ينبغي اتباع ترتيبها. يحتوي كل منهما على عناصر <li>.

استخدم الجدول للبيانات المترابطة في صفوف وأعمدة، لا لترتيب شكل الصفحة. أضف عناوين واضحة للخلايا باستخدام <th>.

النماذج: استقبال بيانات المستخدم

تجمع النماذج مدخلات المستخدم. اربط كل حقل بعنصر <label>؛ فالاعتماد على النص النائب وحده لا يكفي، لأنه يختفي عند الكتابة ولا يقدم تسمية ثابتة.

تحدد action وجهة إرسال البيانات وmethod طريقة الطلب. المثال يوضح البنية فقط؛ معالجة البيانات تتطلب خادمًا أو خدمة مناسبة، ولا يرسل هذا النموذج البيانات بمجرد نسخه كما هو.

استخدم العناصر الدلالية

العناصر الدلالية تصف دور أجزاء الصفحة للمتصفح وأدوات المساعدة ومحركات البحث. بدل وضع كل المحتوى داخل عناصر عامة، استخدم عناصر مثل <header> و<nav> و<main> و<article> و<footer> عندما تناسب معنى المحتوى.

طبّق: أنشئ صفحة تعريف بسيطة

أنشئ صفحة بعنوان «من أنا»، واكتب فقرة قصيرة عنك، وقائمة بمهاراتك، ورابطًا إلى مشروعك. جرّب إضافة صورة مناسبة مع وصف بديل، ثم رتّب المحتوى بعناصر دلالية. بعد ذلك افتح الملف في المتصفح وعدّل الشيفرة ولاحظ النتيجة.

الخلاصة

ابدأ ببنية صحيحة، واختر العنصر وفق معنى المحتوى، واكتب روابط وأوصاف صور واضحة. تدرب على صفحة صغيرة ثم تحقق من عملها في المتصفح ومدقق HTML. وبعد أن تثبت أساس HTML، انتقل إلى CSS للتنسيق وJavaScript لإضافة التفاعل.
